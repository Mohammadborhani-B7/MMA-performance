# MMA Performance — نسخه اولیه PWA

## محتویات
- داشبورد فارسی راست‌چین
- چک‌لیست روزانه، ثبت آب، پروتئین، وزن و گزارش تمرین
- ذخیره اطلاعات در حافظه مرورگر همان دستگاه
- فایل‌های manifest و service worker برای نصب به‌صورت PWA

## نکته مهم
این بسته هنوز روی اینترنت منتشر نشده است. برای نصب واقعی روی آیفون به یک آدرس HTTPS نیاز دارد.
پس از میزبانی:
1. آدرس سایت را در Safari باز کنید.
2. دکمه Share را بزنید.
3. گزینه Add to Home Screen را انتخاب کنید.
4. نام MMA را تأیید و Add را بزنید.

اطلاعات این نسخه محلی است و با پاک‌کردن داده‌های Safari ممکن است حذف شود؛ همگام‌سازی ابری و اعلان‌های مستقل هنوز پیاده‌سازی نشده‌اند.
